## 二、截图要求（建议）

- **格式**：**`.webp`**（体积小、文字仍锐利；本目录现有 7 张合计仅约 0.3 MB）。用 `.png` 也行，但需同步改 README 的扩展名。
- **尺寸**：长边 **1280～1800px** 即可（GitHub 正文显示宽度约 900px，2x 屏也够看）；不要直接放 3000px 的原始截图。
- **暗/亮**：优先截**亮色或统一主题**下的界面，避免混用导致观感割裂。
- **隐私**：截图前**清空 localStorage**、不要露出真实 API Key / 真实域名 / 备案号 / 服务器 IP；必要时打码。
- **体积**：单张控制到 **200 KB 以内**，整目录 **500 KB 以内**，避免 README 加载过慢。

## 三、操作步骤（三步替换占位）

1. **运行游戏**：本地 `pnpm dev` 打开 `http://localhost:3000/meowcha/`，或直接访问你已部署的站点。
2. **截图**：用系统截图工具截取上述界面，改名为上表文件名，放进本目录（`docs/screenshots/`）。
3. **提交**：把图片加入仓库并提交。README 中的 `![...](docs/screenshots/xx-xxx.webp)` 会自动显示对应图片；若文件名与上表不同，请同步更新 README。

> 💡 若暂时没有某张图：**不要删除 README 里的引用行**——GitHub 会显示一个占位破图；也可先在 README 里把该行注释掉（`<!-- -->`）。两者皆可，按你偏好处理。
